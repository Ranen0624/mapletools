# 메이플툴즈 (MapleTools)

공식 홈페이지: https://mapletools.kr/ — 메이플스토리 장비·유니온·코디 검색기

메이플스토리 장비·유니온·코디 검색 도구의 홈페이지, 웹 체험판과 공개 배포 저장소입니다.
제작자: 루나 서버 **케페우스** · 메이플스토리 인벤 **미호** (동일 제작자).

## 현재 공개 버전

| 플랫폼 | 버전 | 배포 파일 |
| --- | --- | --- |
| Windows | **2.0.5** | [PC ZIP](downloads/MapleTools_PC_Public_2.0.5.zip) |
| Android | **1.0.6** | [Android APK](downloads/MapleTools_Android_Public_1.0.6.apk) |

PC는 ZIP 전체를 풀고 `MapleTools.exe`를 실행합니다.
Android는 Android 8.0 이상 ARM64를 지원합니다. 두 공개판 모두 사용자의 NEXON Open API 키를 설정해야 합니다.
파일 크기와 SHA-256은 [releases.json](releases.json), [RELEASE_CHECKSUM.txt](RELEASE_CHECKSUM.txt)에서 확인할 수 있습니다.

## 주요 기능

- 장비 이름·옵션과 성장 조건을 조합한 캐릭터 검색
- 레벨·직업 조합으로 유니온 챔피언 후보 검색
- Android 통합 장비 검색, 입력칸 비우기·조건 복원·휴대폰/태블릿 화면 배치
- 코디 일부 이름 추천·아이콘, 프리스타일·헤어·성형·피부 조건 검색과 코디룸 미리보기
- 코디 세트·패키지·이벤트 623개 그룹과 착용 가능한 추가 보상 확인
- 검색 결과 CSV, 통계, 저장·이어하기 및 변화 기록
- 메이플 장비 추적·검색, 유니온 캐릭터 추적·조회, 닉네임·길드·월드·코디 변화 이력 확인(공개 데이터 범위 내)

웹 체험은 가상 데이터이며 실제 NEXON 캐릭터 API를 조회하지 않습니다.
코디 아이콘·참고 착용 이미지는 아이템 식별코드를 이용해 NEXON 이미지 서버에서 불러옵니다. 일부 망토 효과는 Curma의 정지 이미지로 보완합니다.
홈페이지의 CSV 모아보기는 사용자가 고른 파일을 브라우저에서 처리하며 서버에 보내지 않습니다.

## 배포와 개발

PC 애플리케이션은 Nuitka로 컴파일했고 Android 핵심 Python 코드는 Cython 네이티브 모듈과 R8 최적화를 적용했습니다.
이 보호는 역공학을 완전히 차단하지 않습니다.
개발 원본·개인 API 설정·서명 키·중간 파일·복구 키는 이 저장소에 포함하지 않습니다.
기능 개발은 별도의 개발 원본부터 진행하며, 명시적인 배포 요청이 있을 때만 공개 배포본을 만듭니다.

GitHub Pages는 `main` 브랜치의 루트 디렉터리를 배포합니다. `CNAME`의 `mapletools.kr` 연결을 유지합니다.
2026-10-17 현재 버전 스냅샷부터 Git 이력을 새로 시작했습니다. 이전 Git 이력은 공개 브랜치에 포함하지 않습니다.
사용자용 [기능별 업데이트 안내](updates.html)는 별도 문서이며, 과거 항목의 날짜·버전은 재구성한 기능 정리 기준일로 표시합니다.

## 검증

- PC 회귀 27개·Qt 사용 흐름 8개와 컴파일된 EXE의 홈·장비·유니온·코디 화면 확인
- Android 에뮬레이터의 네이티브 엔진·사용 흐름 28개 통과; 실물 ARM64 휴대폰 검색은 미검증
- 공개 ZIP/APK 무결성, 개인 키·애플리케이션 소스 제외, 홈페이지 다운로드 해시 검증
- `npm test`: 웹 예시 검색·코디 판정·DOM·CSV·메이트 검사
- `python -X utf8 tests/check_site.py`: 내부 링크·버전·공개 파일 해시·JavaScript 구문 검사

자세한 검증 범위는 [QA_NOTES.md](QA_NOTES.md), 설치·이용 범위는 [이용 안내](terms.html)를 참고하세요.

## 미스터리 파일 최초 공개판

`mystery.html`에서 캐릭터 API 검증본의 290~300레벨·직업·월드별 전투력 시상식을 제공합니다. 일반 월드와 에오스·핼리오스는 분리합니다. 초기 384명 시험 표본은 사용하지 않습니다. 날짜별 API 기록을 보존하고 기준일을 선택해 비교합니다. 코디를 누르면 확대할 수 있습니다. [데이터 반영·검증·Cloudflare 확장 안내](docs/mystery-operations.md)를 따르세요.
