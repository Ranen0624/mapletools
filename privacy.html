홈페이지와 웹 체험판

이 홈페이지는 회원가입이나 API 키 입력을 요구하지 않습니다. 웹 체험판은 페이지에 포함된 가상 캐릭터와 수치·기록을 사용하며 NEXON 캐릭터 조회 API를 호출하지 않습니다. 체험판에서 입력하거나 저장한 검색 조건은 현재 페이지를 연 동안 브라우저 메모리에서만 유지되고, 페이지를 새로 열면 초기화됩니다.

홈페이지의 「내 결과 모아보기」에서 선택한 CSV는 브라우저의 별도 작업 스레드에서만 읽고 집계합니다. 원본 파일·캐릭터 식별 정보·통계는 서버로 전송하지 않으며, 브라우저 저장소에도 보관하지 않습니다. 「파일 지우기」를 누르거나 페이지를 닫으면 현재 집계가 사라집니다.

코디 추천의 아이콘과 참고용 착용 이미지는 아이템 식별코드를 이용해 NEXON 이미지 서버에서 불러옵니다. 일부 망토의 별도 효과 이미지는 Curma(mavatar.curma.cc)에서 불러오며 아이템 번호가 사용됩니다. 이미지 요청에는 코디 아이템 번호가 사용되며 NEXON API 키·캐릭터 식별 정보·CSV 내용은 보내지 않습니다. 해당 이미지 서버가 접속 정보를 처리할 수 있습니다.

별도의 분석·광고 추적 스크립트를 사용하지 않습니다. 정적 페이지를 제공하는 GitHub Pages 등 호스팅 사업자는 보안·운영을 위해 접속 로그를 처리할 수 있습니다.

프로그램에서 처리하는 데이터

API 인증 키PC 2.0.4 공개판은 사용자가 입력한 NEXON Open API 키를 PC의 사용자별 설정 파일에 저장합니다. Android 1.0.4 공개판도 사용자가 입력한 키를 앱의 API 요청에 사용합니다. 기기 간 키를 자동으로 동기화하지 않으며, 홈페이지로 키를 전송하지 않습니다.
공개 게임 정보프로그램은 캐릭터명, 월드, 레벨, 직업, 장비, 유니온 등 공개 API가 제공하는 게임 정보를 조회합니다. 조회할 캐릭터 식별 정보와 인증 키는 요청에 필요한 범위에서 NEXON Open API로 전송됩니다.
사용자 기기 기록지원 버전에 따라 검색 조건, 작업 진행·결과, 기록의 백업, 공개 API 응답 캐시를 사용자 기기에 저장할 수 있습니다. 사용자가 선택하면 결과를 CSV 등의 파일로 내보냅니다.
공개 배포 범위홈페이지는 PC 2.0.4과 Android 1.0.4 공개판을 제공합니다. 개인판 프로그램과 개인 API 키, 비공개 서명 키는 배포하지 않습니다.

외부 사이트와 파일 저장

NEXON Open API, GitHub, MapleScouter 등 외부 링크를 선택하면 해당 서비스로 이동할 수 있으며 각 서비스의 개인정보 처리방침이 적용됩니다. 웹 체험판의 CSV는 브라우저에서 가상 결과로 생성합니다. 파일 다운로드는 사용자의 선택으로 시작됩니다.

안내의 범위

프로그램은 API 키나 검색 결과를 홈페이지 운영자의 별도 수집 서버로 전송하도록 설계되어 있지 않습니다. 공개 배포 상태와 실제 기능 범위는 다운로드 안내와 이용 안내에서 확인할 수 있습니다.
