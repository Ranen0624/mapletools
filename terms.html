이용 안내

최종 수정일: 2026-10-17 · PC 2.0.4 · Android 1.0.4 공개판

현재 공개 다운로드는 PC 2.0.4과 Android 1.0.4입니다. 두 공개판 모두 본인의 NEXON Open API 키가 필요합니다. 웹 체험은 PC 2.0.4 화면을 참고한 가상 데이터 예시입니다.

버전별 업데이트 기록 보기 →

1. 설치와 시작

공개 Windows ZIP을 내려받아 완전히 압축 해제한 뒤 MapleTools.exe를 실행합니다. 프로그램과 실행에 필요한 구성 요소를 함께 포함한 컴파일 배포본입니다. 폴더 전체를 함께 보관하고 실행하세요. 공개판은 사용자가 발급받은 NEXON Open API 키를 프로그램 설정에 입력해 사용합니다.

Android 1.0.4 공개 APK는 Android 8.0 이상 ARM64 기기용입니다. APK를 내려받아 설치하고 앱에서 본인의 API 키를 설정하세요. Java 난독화와 파이썬 핵심 모듈의 네이티브 컴파일을 적용한 APK입니다. 작은 화면의 배치와 장비 옵션 표시를 다듬고, 메뉴와 안내를 편한 말투로 바꿨습니다. Android 에뮬레이터에서 컴파일된 엔진의 초기화·진단·조건 검증을 확인했습니다. ARM64 실기기 검색은 아직 확인하지 못했습니다. 개인판과 같은 패키지·서명을 사용하므로 두 앱을 동시에 설치할 수 없습니다. 교체 전 필요한 기록을 내보내세요. 긴 검색은 앱을 열어둔 상태에서 실행하며 백그라운드 작업 완료를 보장하지 않습니다.

2. 검색 도구 선택

  • 장비 검색: 아이템명·스타포스·잠재·에디·추가옵션으로 일치 장비를 찾습니다.
  • 상세 검색: 전투력·총 스타포스·아케인·어센틱포스·유니온·아티팩트의 범위, 길드·생성년도·접속·해방, 가위·주문서·익셉셔널·소울과 HEXA 코어·사용 재화를 조합합니다.
  • 유니온 챔피언: 최대 6개의 직업·레벨 조건과 공개된 챔피언 등록 캐릭터를 비교합니다. 계정의 모든 캐릭터를 열람하는 기능이 아닙니다. 지원 화면에서는 부분 일치도 확인할 수 있습니다.

3. 데이터 범위와 정확성

장비 추적과 유니온 캐릭터 추적이라는 표현은 공개된 데이터에서 대상 캐릭터의 장비·유니온 챔피언 정보를 조건별로 찾아 확인하는 기능을 뜻합니다. 비공개 계정의 전체 캐릭터 목록을 확인하거나 장비 변경을 실시간 감시하는 기능은 아닙니다.

검색은 선택한 랭킹 수집 범위와 공개 API의 제공 범위에 한정됩니다. 기준일·캐릭터 공개 여부·갱신 시점·API 응답 누락에 따라 결과가 달라집니다. 지원 버전의 장비·상세 검색은 누락된 필수 값을 다시 조회하고, 복구되지 않은 대상은 미확인으로 남깁니다. 수집 한도에 도달하면 범위 제한을 표시합니다.

기본 전투력 검색은 API가 제공하는 값을 사용합니다. 직접 전투력 검산은 장비·세트·럭키아이템·칭호·캐시·펫·안드로이드·계정 효과 등을 공개 정보에 따라 합산하고 출처와 차이를 표시합니다. API와 계산 입력의 시점 차이, 만료 정보의 잔존, 직업별 산식 검증 한계가 남아 있으므로 모든 캐릭터의 정수 일치를 보장하지 않습니다.

다른 프리셋 전투력 유추는 기본 해제입니다. 현재 계산의 정수 일치와 입력 검증 등 조건을 통과한 일반 직업에서만 검색에 사용합니다. 제논·데몬어벤져는 프리셋 유추 검색에서 제외하며, 해당 직업의 참고 추정과 일부 일리움·엔젤릭버스터 자료의 차이는 해결됐다고 판정하지 않습니다. 저장 표본의 일치는 실제 게임 내 프리셋 전환 정확도나 모든 캐릭터의 정확도를 뜻하지 않습니다.

4. 저장·이어하기·통계

PC 공개판에서는 이름 붙인 조건 저장, 결과와 진행 기록 복원, 장비·상세 검색 이어하기와 실패 대상 재조회를 지원합니다. 현재 정보 검색을 이어갈 때는 기존 결과도 다시 검증합니다. 저장 조건과 결과는 서로 다른 기록이며 복원된 결과가 자동으로 최신 상태가 되는 것은 아닙니다. 유니온 이어하기는 플랫폼과 화면별 지원 차이가 있습니다.

통계는 같은 월드·닉네임을 한 명으로 집계하며, 한 캐릭터의 여러 일치 장비가 인원수를 늘리지 않습니다. 통계의 모집단은 수집한 검색 결과이며 메이플스토리 전체 직업 인구를 의미하지 않습니다.

5. 변화 이력과 내보내기

공개 자료가 존재하는 기간 안에서 닉네임·길드·월드·성별 변화, 레벨 달성일과 코디 기록을 확인합니다. 누락 날짜는 변화가 없었다고 확정하지 않으며, 최초 확인일이 게임 내 실제 변경 시각과 다를 수 있습니다.

지원 버전에 따라 결과 모아보기표를 CSV로 저장할 수 있습니다. Android 전체 기능 화면의 이미지는 최대 240줄, PDF·인쇄는 현재 표시한 결과 페이지를 대상으로 합니다. 전체 결과 목록은 CSV로 내보내세요.

6. 웹 체험판

코디 착용자 검색은 PC와 같은 부분 이름·수량·프리셋별 일치 규칙을 사용합니다. 입력한 아이템·헤어·성형·피부 조건은 같은 구성에서 모두 맞아야 하며, 입력하지 않은 부위는 제한하지 않습니다. 프리스타일 적용 코디를 성별로 제외하지 않습니다. 추천 이미지와 착용 미리보기는 외부 리소스 기준의 참고 이미지이며 최신 아이템·믹스·프리즘을 모두 재현하지는 않습니다. 기본 외형·아이콘은 NEXON, 일부 망토의 별도 효과는 Curma의 정지 이미지를 사용합니다. 세트·패키지·이벤트 코디 623개 그룹과 착용 가능한 추가 보상을 제공하며, 모든 그룹이 게임 내 능력치 세트 효과를 의미하지는 않습니다. 2026-10-14의 가상 기록만 제공합니다. PC 공개판 2.0.4에는 코디 검색기가 통합되어 있습니다. Android 공개판은 1.0.4입니다.

웹 체험판은 기능 흐름 설명을 위한 별도 예시입니다. 가상 데이터에 입력 조건을 적용하는 검색·정렬·필터·통계·CSV와 현재 페이지 동안의 조건 저장을 제공합니다. 전투력 분석은 미리 구성한 가상 보고서이며 PC의 실제 전투력 산식을 실행하지 않습니다. 통합 홈, 상단 메뉴, 장비 세부옵션 묶음, 닉네임 팝업과 추천 목록, 잠재·에디 3줄·등급·순서, 추옵 4개, HEXA 종류별 4칸과 유니온 6칸의 구성을 원본에 맞췄습니다. 기운·조각은 HEXA 스킬 누적 소모량 예시이며, 스탯 추가는 미리 정한 가상 비용 범위로 체험하며 보유 재료·초기화·이벤트 비용은 포함하지 않습니다. 웹 폭에 맞게 일부 배치와 세부 조건은 조정했으며, 원본의 모든 옵션과 실제 조회를 재현하지는 않습니다.

7. 비공식 프로젝트

MapleTools는 NEXON 및 메이플스토리의 공식 서비스가 아닙니다. 관련 게임·상표·이미지·데이터의 권리는 각 권리자에게 있습니다. 실제 API 사용에는 NEXON Open API의 정책과 약관이 적용됩니다.
