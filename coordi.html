도움말

코디 검색 조건과 결과 확인 방법을 안내합니다.

아이템·헤어·성형·피부 이름을 쉼표나 줄바꿈으로 나눠 입력하세요.

  • 선택한 코디 모두 일치: 입력한 코디를 모두 착용하면 다른 장비가 있어도 찾아요.
  • 캐시 장비 전체 구성 일치: 입력한 캐시 장비 외의 다른 캐시 장비가 있으면 제외해요.
  • 이름 일부만 입력해도 찾으며, 프리스타일 아이템을 성별로 제외하지 않아요.
  • 같은 이름을 두 번 입력하면 같은 아이템 두 개가 필요해요.
  • 기본·프리셋·추가 외형을 각각 확인해요. 서로 다른 프리셋을 섞지 않아요.
  • 결과를 선택하면 일치한 구성과 상세 목록을 볼 수 있어요.

가상 캐릭터로 체험하는 화면이에요. 실제 검색은 PC 프로그램에서 진행해 주세요.
