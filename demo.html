유니온 검색 옵션

조회 수와 페이지 한도는 화면 설정 예시예요. 실제 네트워크 요청은 하지 않아요.

원본 프로그램처럼 사용해 보세요.

  1. 통합 홈에서 장비·유니온챔피언·코디 검색기를 선택합니다. 코디 체험은 별도 프로그램 0.5.1을 참고했습니다.
  2. 상단 검색 조건에서 장비·전투력·HEXA 조건을 함께 입력합니다.
  3. 하단 검색 시작 버튼을 누르고 결과 표에서 캐릭터를 선택합니다.
  4. 상세 창에서 전투력 분석·변화 이력·코디 기록을 확인합니다.
  5. 검색 결과 안의 결과 통계 탭에서 캐릭터 중복을 제거한 분포를 확인합니다.
  6. 검색 결과에서 전체 스펙 표를 보고, 선택 캐릭터 요약을 펼치거나 장비·스펙 보기로 상세 창을 엽니다.
  7. 설정에서 공통 속도·첫 화면과 유니온 완전 일치 옵션을 바꿔볼 수 있습니다.

웹 체험의 캐릭터·수치·기록은 모두 가상입니다. 날짜·페이지 한도는 화면 조작 예시이며 실제 API를 조회하지 않습니다. 전투력 화면은 가상 보고서입니다.
