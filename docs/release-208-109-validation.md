# PC 2.0.8 / Android 1.0.9 검증

검증일: 2026-10-31.

[NEXON AI 에이전트 가이드](https://openapi.nexon.com/ko/guide/ai-agent/)를 검토하여 필요한 부분을 적용했습니다. 키 해시를 포함한 디스크 캐시 주소로 키 변경 시 이전 키의 응답 재사용을 막습니다. 영구 캐시의 요청 주소에는 쿼리 원문을 저장하지 않으며 기존 키 구분이 없는 SQLite API 캐시는 재사용하지 않습니다. HTTP 200이어도 날짜 외 필드가 모두 null인 응답과 키 조각 포함 응답은 저장하지 않습니다. 정상 캐시의 최대 29일 보관과 일시적인 메모리 캐시의 만료를 유지합니다.

OPENAPI00003·00004는 재시도하지 않고 OPENAPI00009는 한 번만 재시도합니다. 점검 오류 00010·00011과 일시 오류에는 지수 대기 및 무작위 지연을 적용합니다. 호출량 제한의 Retry-After 최소 대기와 사용자 취소 기능을 유지합니다. 오류 안내에 응답 메시지·쿼리 원문을 그대로 붙이지 않습니다.

PC 회귀 41개와 수집기 회귀 193개(1개 건너뜀), PC/Android 공통 모듈 17개·작업 정의 12개 일치를 확인했습니다. 네이티브 PC 실행 파일 및 Android 15 x86_64에서 각각 15개의 합성 API 프로토콜 검사를 실행했습니다. 외부 API 호출 없이 키별 실제 SQLite 캐시 분리·null 응답·키 조각 저장 차단·재시도 횟수·취소·오류 비노출을 확인했습니다.

PC 홈·장비·유니온·코디 화면과 공유 치장 200개, 실제 API 전투력 4개의 정확 일치, 계산 제한 원본 114개의 API 값 보존을 확인했습니다. Android 네이티브 치장 200개와 실제 WebView의 같은 200개, 전투력 및 기존 설정을 유지하는 19→20 업데이트도 확인했습니다.

공개 PC는 64개 앱 모듈을 컴파일했습니다. ARM64 APK는 26개 모듈 네이티브 빌드, 원본 해시, R8/lint, 기존 서명 일치, 16KB 정렬과 압축 무결성을 검사했습니다. ARM64 실기기는 확인하지 않았습니다. 개발 소스·개인 키/키 조각·서명 자료·테스트 자산·생성 C·R8 매핑을 공개 파일에서 검사하고 제외합니다. 실제 배포 파일의 SHA-256을 재검증합니다.

이번 프로그램 배포는 명예의전당 순위·전투력·코디 자료를 변경하지 않습니다. 공개 식별자 익명화는 앞선 별도 웹 수정으로 적용했습니다. 과거 Git 커밋은 다시 작성하지 않았습니다.
