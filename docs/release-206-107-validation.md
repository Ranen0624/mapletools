# PC 2.0.6 / Android 1.0.7 검증

검증일: 2026-10-24.

장비 date_expire가 `expired`인 응답을 기존 만료 판정 함수로 처리하도록 수정했습니다. 만료 장비를 활성 상태로 복원하거나 원본에 없는 효과를 추가하지 않습니다. 실제 14개 원본에서 분류만 바뀌고 전투력 선택값이 유지되는 것을 확인했습니다.

PC 회귀 테스트 27개, 수집·계산·만료·보관 회귀 테스트 49개, Android 유니온 입력 검증 3개와 코디 일치 240개 검사를 통과했습니다. 새 PC 실행 파일에서 63개 애플리케이션 모듈의 네이티브 컴파일, 홈·장비·유니온·코디 화면과 실제 전투력 자료 4건의 정확 일치를 확인했습니다.

Android 15 x86_64 에뮬레이터의 Cython 네이티브 엔진에서도 같은 4건의 정확 일치, 실제 원본 114건의 API 전투력 보존과 계산 제한 표시, 코디 WebView 동작을 확인했습니다. versionCode 17에서 18로 앱 삭제 없이 업데이트하고 저장 설정이 유지됐습니다. ARM64 공개 APK는 원본 25개 모듈의 컴파일 해시·기존 서명 일치·16KB 정렬·R8·lint와 ZIP 무결성을 검사했습니다. ARM64 실기기 검증은 수행하지 않았습니다.

114건은 23일 원본의 프리셋 계산까지 모두 복구됐다는 뜻이 아닙니다. 49건은 만료 장비 42건, 무기·직업 지원 부족 6건, 무기 미착용 1건입니다. 전부 재조회했으나 원본이 같았습니다. 나머지 65건은 23일 유니온 챔피언 자료가 없으며, 현재 시점 조회는 모두 성공하고 식별자 변경은 없었습니다. 현재 효과를 과거 날짜에 복사하지 않으며 실제 API 전투력은 그대로 표시합니다.

명예의 전당 순위와 23일 운영 원본은 이번 프로그램 배포에서 변경하지 않았습니다. 원본·캐릭터 식별자·테스트 픽스처·개인 키·개인 설정·서명 키·생성 C·R8 매핑은 공개 파일에 포함하지 않습니다. CRC·SHA-256과 공개 파일 검사를 통과한 두 파일만 다운로드에 연결합니다.
