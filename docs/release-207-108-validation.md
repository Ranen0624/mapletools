# PC 2.0.7 / Android 1.0.8 검증

검증일: 2026-10-30.

월드 공유 기본 치장 슬롯을 실제 활성 상태·부위·성별에 따라 코디 검색과 상세에 반영했습니다. 엔젤릭버스터 일반/드레스 업과 제로 알파/베타 적용을 구분하고 저장 코디 프리셋은 독립된 API 목록으로 유지합니다. Android의 캐시 옵션·유효기간 상세도 공유 기본 장비를 사용합니다. 전투력 계산식과 순위 선정 정책은 그대로입니다.

PC는 새 공통 모듈을 포함한 64개 애플리케이션 모듈의 네이티브 컴파일과 실제 Windows 홈·장비·유니온·코디 화면을 확인했습니다. 저장 응답 기반 공유 치장 선택 200건, 실제 전투력 4건의 정확 일치와 계산 제한이 있는 기존 원본 114건의 API 값 보존을 실행 파일에서 검사했습니다. Android의 과거 코디 조회 작업에도 확인된 직업을 전달하며, 공통 코어 17개와 작업 정의 12개가 PC와 동일함을 확인했습니다. PC 회귀 27개, 공유 치장 경계 9개, PC/Android 코디 비교 240개도 통과했습니다.

Android 15 x86_64 에뮬레이터에서 새 네이티브 모듈의 공유 치장 선택 200건과 실제 WebView의 같은 200건을 확인했습니다. 전투력 4건·기존 제한 원본 114건, 코디 추천·세트·추가 보상 화면도 검사했습니다. 기존 1.0.7(versionCode 18)에서 앱 삭제 없이 1.0.8(19)로 업데이트하고 실제 저장 설정이 유지됐습니다.

공개 ARM64 APK는 26개 Python 모듈의 네이티브 빌드·원본 해시·기존 서명 일치·16KB 정렬·R8·lint·ZIP 무결성을 검사했습니다. ARM64 실기기 검증은 수행하지 않았습니다. PC ZIP은 전체 압축을 풀어 실행하며 기존 설정과 기록은 이전 폴더의 user_data를 새 폴더로 복사해 유지할 수 있습니다.

개인 API 키·개인 설정·개발 Python·테스트 픽스처·서명 키·생성 C·R8 매핑은 공개 파일에 포함하지 않습니다. 검증한 두 파일의 SHA-256과 다운로드 연결을 함께 갱신하며 명예의전당 데이터는 보존합니다.
