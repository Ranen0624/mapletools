# PC 2.0.9 / Android 1.0.10 검증

검증일: 2026-11-16. Android versionCode: 21.

검색 중지·이어하기, 키·속도 변경, 반복 검색의 작업 정리, 오류·저장 실패,
늦은 응답으로 인한 화면/결과 덮어쓰기와 종료 처리를 보완했습니다.
PC 2.0.8과 이전 Android 내부 기록 형식을 조건·무결성 확인 후 이어갈 수 있습니다.

소스 검사 81건: PC 60건, Android Python 엔진 11건, 앱 HTML/JavaScript DOM 10건.
가상 캐릭터와 응답으로 검사했으며 실제 넥슨 API 호출이나 전량 검색은 하지 않았습니다.

공개·개인 PC 실행파일 각각 네이티브 API 프로토콜 15건과 사용 흐름·업데이트 호환 19건을 통과했습니다.
홈·장비·유니온·코디 화면의 실제 실행 및 화면 표시도 확인했습니다.
테스트 대기는 배포물에 없는 QtTest 대신 동일한 Qt 이벤트 루프를 사용했습니다.

Android ARM64 공개·개인 APK 각각 빌드와 lint, 26개 앱 모듈 네이티브 컴파일,
원본 해시 일치, 기존 인증서와의 서명 일치, 16KB 정렬 및 ZIP 무결성을 확인했습니다.
공개 배포물은 원본 앱 소스·개인 API 키/키 조각·서명 자료·생성 C·테스트 자산을 검사해 제외했습니다.

이 버전은 실제 휴대폰 및 에뮬레이터 실행을 검증하지 못했습니다.
검사 PC의 Android 가속 드라이버가 없고 소프트웨어 모드 가상 기기도 부팅되지 않았습니다.
에뮬레이터용 테스트 APK는 빌드했지만 이를 실행 성공으로 표시하지 않습니다.
이전 버전의 기기 실행 검증 결과도 이번 버전 결과로 승계하지 않습니다.
기존 서명·앱 ID 유지와 설치 번호 증가를 확인했으나 실제 기기의 덮어쓰기 설치는 별도 미검증입니다.

이번 배포는 다운로드와 버전 안내만 갱신하며 명예의전당 자료와 CNAME은 유지합니다.
