# 2026-10-29 착용 전투력 정확 검증 — 2026-11-02

사용자 요청으로 10월 29일 저장 원본만 재검증했습니다. 최신 10월 31일과 다른 날짜의 활성 순위·코디 및 PC 2.0.8·Android 1.0.9 배포 파일은 보존합니다.

## 수정한 공통 처리

- `preset-api-v19`는 현재 착용 전투력을 먼저 독립 계산하여 같은 날짜 API 정수 값과 정확히 일치하고 원본 상태 경고가 없을 때만 프리셋 후보를 허용합니다. 진단 옵션으로 이 조건을 우회할 수 없으며 최댓값 선택 단계에서도 다시 검사합니다.
- 최고 탄약 가정을 현재 착용 검산에 넣던 처리를 분리했습니다. API가 실제 사용 화살·표창·불릿을 제공하지 않으므로 7개 탄약 직업은 같은 날 API 착용값만 사용합니다. 수치에 맞춰 탄약을 역산하지 않습니다. [공식 업데이트](https://maplestory.nexon.com/News/Update/741)는 탄약 공격력이 전투력에 반영됨을 확인하지만 실제 사용 탄약을 API로 확인할 근거를 제공하지 않습니다.
- 착용 불일치·원본 부족·갱신 시점 경고가 남은 경우 계산 후보를 보류하고 실제 API 값은 보존합니다. 캐릭터 이름별 예외, 정답 비율 보정, 미확인 옵션 추가는 없습니다. 일반 산술식 자체를 전부 수정·확정했다고 주장하지 않습니다.
- 새 행의 `equipped_validation_policy=equipped-exact-v1`을 웹·공개 변환기·CSV에서 검사합니다. 검증 전 행과 한 수집본에 섞지 않습니다. 기존 날짜의 v18 정책은 소급하여 이름만 바꾸지 않습니다.
