# 전투력 명예의 전당 운영

## 공개 범위

290~300레벨의 전투력을 날짜·직업·월드별로 비교합니다. 일반 월드와 에오스·핼리오스를 분리하며 제논·데몬어벤져는 전체 집계와 직업 검색에서 제외합니다. 최신 기준일과 검증 인원은 data/mystery-dates.json 및 data/mystery-collection.json에 기록합니다. 후보 목록 밖 캐릭터·API 미제공·계산 검증 보류가 있어 수집본 내 순위로 표시합니다. 가상 순위·대체 이미지를 만들지 않습니다.

이전 285레벨 수집 작업의 후보 741,867명 중 363,503명을 실제 조회했습니다. 최소 레벨을 290으로 변경한 뒤 탐색 경계 미만의 미조회 378,364명은 skipped로 구분했고 조회 인원에 넣지 않았습니다. 이미 수집한 낮은 레벨 기록과 원래 체크포인트는 비공개 PC에 보존했습니다. 최초 384명 시험 표본은 공개 순위에 사용하지 않습니다.

## 데이터 기준과 수집

후보 이름 탐색에만 ranking/overall API를 사용합니다. 탐색은 289레벨을 경계 완충 범위로 포함하고 인원 제한 없이 페이지를 확인합니다. 실제 등재 레벨·직업·월드·이름·코디는 character/basic으로 확인합니다. 경험치 랭킹 순위로 시상식을 결정하지 않습니다.

2026-10-20부터 오늘의 날짜 없는 API 자료를 강제 갱신하여 장비·하이퍼·어빌리티·유니온 프리셋 조합을 계산합니다. 전투력 수치에 맞춘 캐릭터별 계수나 과거 최고 기록을 쓰지 않습니다. 현재 착용 상태를 공개 옵션·AP로 독립 재구성하여 character/stat 전투력과 정확히 일치하는지 먼저 검사합니다. 장비를 교체하면 실제 set_option_full과 장비 구성으로 세트 효과를 다시 계산하고 유효기간이 끝난 옵션은 적용하지 않습니다. 확인할 수 없는 프리셋이 최대값을 바꿀 수 있으면 해당 캐릭터를 검증 보류합니다. 안드로이드가 불명확한 경우 심장 활성 상한조차 확인된 최대값 이하일 때만 그 프리셋을 생략할 수 있습니다. 조회 전후 전투력이 바뀌면 다시 조회하고, 불일치가 남으면 보류합니다.

공개 calculation 필드에는 API 착용 전투력, 일치한 검산값, 선택한 프리셋 번호, 계산기 버전, 실제 조회 시각과 비교 조합 수만 저장합니다. UI는 ‘프리셋 계산 전투력’으로 명시하며 착용 API 수치와 한 순위로 섞지 않습니다. 2026-10-19 기록은 착용 API 기준으로 남기고 기준을 별도 표시합니다. 날짜가 다르거나 실제 자료가 없는 값은 채워 넣지 않습니다.

키는 기존 개인용 프로그램의 로컬 설정을 통해 메모리에서만 재사용합니다. Python 수집 소스·설정·로그·원본 JSONL·SQLite·캐시는 공개 저장소 밖에 둡니다. 공개 PC 2.0.4 ZIP, Android 1.0.5 APK, releases.json과 CNAME을 보존합니다.

## 매일 축적

매일 오전 6시(Asia/Seoul) 오늘 자료를 수집하는 로컬 예약을 등록했습니다. PC와 데스크톱 앱이 실행 중이어야 합니다. 비공개 run_daily.py는 새 날짜 후보를 탐색하고 collect_preset_sources.py 체크포인트를 이어받아 프리셋별 실제 API 자료를 먼저 비공개 저장합니다. 자격 정보가 없는 공통 계산기 preset_batch.py가 여러 프로세스에서 일괄 계산하고 검증 통과분만 공개 파일로 만듭니다. 저장한 안정된 자료는 API 재조회 없이 재계산할 수 있습니다. 같은 날짜에 일부 공개본이 이미 있어도 남은 후보를 이어갑니다. 중복 실행은 잠금으로 막고 실시간 수집 중 한국시간 자정이 지나면 중단합니다. 사용자가 매일 검증 후 자동 공개까지 명시적으로 허용했습니다. 수집·검증 후 데이터 PR 생성, CI 통과 시 병합·배포까지 진행합니다. 수집·검증·배포 실패 시 이전 공개본을 유지하고 실패를 알립니다.

## 공개 파일 준비

```text
node scripts/publish-mystery-index.mjs 검증본.jsonl 완료기록.json 저장소경로 --archive
```

기본값은 pending/error/unverified가 남은 작업의 공개를 거절합니다. 사용자가 중간 공개를 요청했으므로 --allow-partial로 검증 통과분만 공개할 수 있고 대기·오류·계산 검증 보류 인원을 기록합니다. 미검증 캐릭터를 착용 전투력으로 대신 등재하지 않습니다. 페이지에는 일부 수집과 순위 변동 가능성을 표시합니다. 공개 인원은 해당 공개본의 고정된 시각 기준이며 실행 중 수집기의 최신 진행 수와 구분합니다. 검사 후 전용 개발 브랜치/PR을 만들고 CI 성공을 확인한 뒤 배포합니다.

```text
npm test
node scripts/check-mystery.mjs
python -X utf8 tests/check_site.py
```

비공개 audit_public.py로 압축을 해제한 데이터까지 실제 로컬 키와 비밀정보 포함 여부를 검사합니다. 공개 원본에는 허용한 캐릭터 필드만 남깁니다. PC 검색 결과의 수동 반영은 scripts/import-mystery.mjs와 data/mystery-template.csv를 사용합니다. 홈페이지의 내 파일 미리보기는 기기에서만 처리하며 업로드하지 않습니다.

## 날짜별 저장 구조

mystery-config.json의 staticCatalog가 data/mystery-dates.json을 가리킵니다. catalog.latest가 최신일이고 dates[].index가 해당 날짜의 변경 불가한 목록을 가리킵니다. 선택한 날짜가 없으면 미수집으로 표시하며 다른 날짜로 대체하지 않습니다. 공유 링크는 date=YYYY-MM-DD를 지원합니다.

schema_version=2 목록은 query별 레벨 인원수와 상위 10명 참조를 저장합니다. 캐릭터는 날짜별 공유 풀에 한 번만 저장하고 gzip/base64 JSON으로 압축합니다. 브라우저는 선택 부문에 필요한 풀만 읽고 검증합니다. 레벨별 TOP 10의 합집합은 임의의 레벨 구간 TOP 10을 정확히 보존합니다. 표시 인원은 전체 API 검증 수이며 저장된 상위 행 개수와 구분합니다. JSON/CSV 다운로드는 선택한 검증 기록으로 기기에서 생성합니다.

새 파일을 모두 기록한 뒤 catalog를 원자적으로 교체합니다. 사용자가 최근 7일 보관을 명시적으로 요청했으므로 mystery-config.json의 historyRetentionDays 기본값은 7입니다. 최신 공개일을 포함한 최근 7개 달력 날짜를 유지하며 새 공개 시 scripts/mystery-retention.mjs가 기간이 지난 순위 풀·수정 전 파일·코디 상세·이전 방식의 조회 JSON/CSV를 정리합니다. 다른 파일과 PC·Android 배포물은 정리 대상에 포함하지 않습니다. 공개 기간 밖 과거 날짜의 재등록은 거절하며 최신일을 뒤로 돌리지 않습니다. 날짜별로 사용자가 내려받은 CSV는 계속 개인 기록으로 분석할 수 있습니다. Git 이력의 기존 커밋을 강제 재작성하지 않습니다.

용량 보호는 데이터 외 배포물·정적 자산까지 포함한 현재 공개 작업 폴더를 계산하며, 기간이 지난 파일을 제외해도 900MiB를 넘으면 공개 준비를 중단합니다. 이 검사는 1GB Pages 한도에 여유를 두기 위한 것이며 전송량 한도를 보장하지 않습니다. 보관 기간 확대 시 historyRetentionDays와 예상 사이트 용량을 함께 확인하세요. Worker/D1은 아직 연결하지 않았고 현재는 GitHub Pages만 사용합니다. 추후 키는 Worker secrets에만 둡니다.

## 캐릭터 상세와 개인 CSV 분석

1~10위의 이름 또는 시상대 이미지를 누르면 같은 기준일의 캐릭터 정보를 엽니다. 큰 공식 이미지·월드·직업·레벨·기준일·전투력·계산 프리셋을 즉시 표시합니다. 추가 코디 정보는 실제 저장된 character/basic 및 character/cashitem-equipment의 동일 캐릭터 자료에서 비공개 export_character_details.py로 추출하고 scripts/publish-mystery-details.mjs로 공개합니다. 실제 착용 코디 프리셋과 전투력 계산 조합을 구분합니다. 코디 아이템명·부위·라벨·컬러링 프리즘 및 길드·성별만 허용하며 미수집 헤어·성형을 추정하지 않습니다. 이름·월드·기준일·이미지 주소 해시를 대조하고, 자료가 없거나 일치하지 않으면 표시를 보류합니다. 캐릭터 상세 풀도 압축하며 클릭했을 때만 읽습니다. daily 수집 후 순위와 상세 정보를 함께 생성·검증하세요.

개인 CSV/JSON은 브라우저 메모리에서만 분석합니다. 파일의 실제 기준일을 사용하며 여러 날짜가 있으면 날짜별로 분리합니다. 날짜 열이 없을 때만 사용자가 입력한 기준일을 적용합니다. 공개 7일 보관 규칙은 개인 파일에 적용하지 않습니다. 선택한 날짜·직업·월드·레벨에 맞는 파일 내 순위와 최고·평균·중앙값을 표시하며, 홈페이지 공개 순위와 섞지 않습니다. API 재계산이나 미수집 코디를 만들어 내지 않습니다. 파일은 서버로 보내거나 저장하지 않고 새로고침하면 사라집니다. 5MiB/50,000행 이내, 290~300레벨의 유효한 정수 전투력 기록을 지원합니다.
