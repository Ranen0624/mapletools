# 전투력 명예의 전당 운영

## API 착용값·가정 프리셋 최댓값 — 2026-10-24 사용자 변경 승인

`preset-api-v18`은 같은 날짜의 실제 API 착용 전투력과 계산 가능한 프리셋 전투력 중 높은 값을 사용합니다. API가 높거나 같으면 반환된 API 정수를 그대로 사용하고, 계산값이 더 높으면 최고급 탄약 가정 등을 적용한 해당 프리셋 계산값을 사용합니다. 착용 전투력의 정확 검산 불일치는 수치·상태로 남기며 공개 보류 조건으로 쓰지 않습니다. 이는 이전 v17의 정확 일치 필수 조건을 대체합니다.

계산에 필요한 칭호·세트·현재 프리셋 등이 부족하면 해당 프리셋을 계산했다고 표시하지 않습니다. 계산할 수 있는 조합이 있으면 그 범위의 최댓값과 API를 비교하고, 전혀 계산하지 못하면 실제 API 착용값으로 포함합니다. 없는 옵션을 만들거나 API 전투력에 맞춰 능력치·탄약을 역산하지 않습니다. API가 실제 0을 반환한 기록도 0으로 보존하며, API 전투력 자체가 없는 기록은 만들지 않습니다. 사냥 프리셋은 계산 후보에서 제외하지만, 실제 API 착용 전투력은 사용자의 새 최댓값 규칙에 따라 그대로 비교합니다. 제논·데몬어벤져 제외는 유지합니다. 모든 장비 프리셋이 사냥 세팅이어도 실제 API 착용값은 포함합니다.

`selection_policy=api-or-calculated-maximum-v1`을 공개 기준과 각 행에 기록합니다. `selected_source=api/preset`, `api_combat`, `preset_combat`(계산 불가 시 null), `baseline_combat`, `baseline_status`, `search_complete`로 출처와 비교 범위를 남깁니다. API가 선택돼도 비교한 계산 후보는 보존하며, 선택하지 않은 안드로이드·코디 조합을 장착 조건으로 표시하지 않습니다. 화면·상세·CSV에도 API 착용값과 가정 프리셋 선택을 구분합니다. 날짜·식별자·290~300레벨·일반/에오스·핼리오스 분리와 실제 코디 확인 조건은 유지합니다.

## v17 이력: 최고 공격력 탄약 가정 — 2026-10-24 사용자 변경 승인

`preset-api-v17`부터 탄약을 직접 확인해야 한다는 이전 조건을 사용자의 명시적 요청으로 변경했습니다. 보우마스터·신궁·윈드브레이커·와일드헌터는 티타늄 화살 공격력 +9, 나이트로드·나이트워커는 플레임 표창 +29, 캡틴은 자이언트 불릿 +22를 보유한 것으로 고정 가정합니다. 전투력에 맞춰 다른 탄약을 선택하거나 역산하지 않습니다. 실제 인벤토리 보유를 확인했다는 뜻은 아니며, 공개 기준과 캐릭터 상세에 가정을 표시합니다.

`ammunition_policy=maximum-projectile-assumed-v1`을 수집 기록·공개 기준·각 계산 행에 남깁니다. 해당 직업의 `calculation.ammunition`은 이름·공격력·`inventory_confirmed=false`를 포함합니다. 현재 착용 상태의 전투력 정확 검산, 날짜 일치, 사냥 프리셋 제외, 세트·캐시·안드로이드와 변경 프리셋의 확인 조건은 유지합니다. 최고 탄약 가정에서도 착용 전투력을 재현하지 못하거나 다른 근거가 부족하면 계속 계산 보류합니다. 탄약 가정으로 인한 실제 보유와의 차이는 허용된 계산 전제입니다.

22일 저장 원본의 탄약 보류 22,454명을 네트워크 없이 재계산했습니다. 기존 비탄약 검증 기록은 계산식을 변경하지 않고 버전·정책 메타데이터만 이관하며, 캐릭터 식별·직업·레벨·전투력의 전체 해시가 같음을 확인합니다. API 원본은 수정하지 않습니다. 이 변경은 23일 이후 새 날짜 수집이나 PC·Android 프로그램 배포를 뜻하지 않습니다.

## 이전 정책: 직접 확인한 탄약만 허용·조회 오류 재시도 — 2026-10-24

사용자 선택에 따라 `preset-api-v16`에서도 사용 탄약은 직접 확인된 근거가 있어야 합니다. 전투력에 맞춰 탄약 공격력을 역산하거나 최대 공격력의 화살·표창·불릿을 기본값으로 넣어 공개하지 않습니다. 7개 탄약 직업의 날짜 지정 2·3차 스킬 응답도 추가 확인했으나, 스킬 고유 공격력과 소비 방식 설명만 있고 실제 보유·사용 탄약은 제공되지 않았습니다. 확인되지 않은 기록은 계속 검증 보류합니다. 모든 장비 프리셋이 지정 사냥 아이템을 포함하면 탄약 직업에도 동일하게 순위 제외 정책을 먼저 적용합니다.

기존 조회 오류는 같은 22일 기준으로 재시도했습니다. 추가로 확보한 날짜 고정 원본은 검산을 거친 뒤 포함하며, 기존 원본을 최신 시점 자료로 덮어쓰지 않습니다. HTTP 200이어도 기본정보의 캐릭터명·월드·직업·레벨이 비어 있으면 성공으로 보지 않습니다. 현재 이름의 식별자를 다시 조회해 다른 식별자가 확인될 때만 같은 날짜의 기본정보를 재요청합니다. 그래도 비어 있으면 `character/basic:empty_snapshot`으로 남기며 `TypeError`나 범위 밖 캐릭터로 잘못 처리하지 않습니다. 홈페이지에서 챔피언 오류·기본정보 없음·이름 식별정보 조회 실패를 구분합니다.

블랙 보조무기·메이플 트레져·일부 시그너스 장비 등을 포함한 39개 정확한 아이템명의 세트 소속을 추가했습니다. 각 이름은 최소 5개의 독립된 동일 날짜 API 세트 개수로 대조했으며 전투력 정답을 분류에 사용하지 않습니다. 럭키 무기가 유지된 조합에서도 실제 반환 개수와 native 개수 및 3개 경계를 재검사합니다. 경험치·드롭률만 남은 종료 스킬의 문자열 때문에 전투 조합을 일괄 보류하지 않지만, 종료된 전투 옵션의 갱신 충돌은 계속 보류합니다. 제네시스의 파괴의 얄다바오트는 [공식 설명](https://maplestory.nexon.com/news/update/682)상 최종 데미지 효과이며 이 전투력 모델의 계산 항목에 넣지 않으므로, 현재 다른 무기를 착용해 스킬 목록에 없다는 이유만으로 실제 제네시스 장비 프리셋을 막지 않습니다. 장비 옵션·세트 효과·기준 착용 전투력 검산은 계속 필요합니다.

## 사냥 프리셋 제외·월드리프 식별·원본 하루 보관 — 2026-10-23

사용자 요청에 따라 `preset-api-v14`부터 어비스 헌터 링·어비스 헌터스 링·정령의 펜던트·스페셜 정령의 펜던트가 있는 장비 프리셋을 최대값 비교에서 제외합니다. 모든 장비 프리셋이 이 조건에 해당하면 순위 대상에서 제외합니다. 사냥 프리셋 제외는 경험치 옵션으로 전투력 상한을 추정한 결과가 아니라 사용자가 정한 집계 기준입니다. 다른 경우 현재 착용 전투력의 독립 검산은 계속 정확히 일치해야 합니다. 현재 착용 프리셋 자체가 제외되면 남은 프리셋의 최대값이 API 착용 전투력보다 작을 수 있으므로, 제외한 프리셋과 집계 정책을 공개 자료·화면·개인 CSV에 명시합니다. 집계 정책이 다른 기록은 한 순위에 섞지 않습니다.

월드리프·개명으로 후보와 실제 응답의 이름·월드가 달라졌다는 이유만으로 보류하지 않습니다. [NEXON 공식 안내](https://openapi.nexon.com/ko/support/notice/2450396/)처럼 월드리프 시 식별자도 바뀔 수 있으므로, 요청한 날짜의 식별자와 `character/basic`의 실제 정보를 확인합니다. 같은 식별자의 중복 후보는 한 번만 등재하고, 같은 날짜 원본의 실제 신원이나 계산값이 충돌하면 보류합니다. 장비 세트 재구성은 API가 반환한 현재 세트 개수에 실제 변경 장비의 영향을 반영하며 럭키 무기의 개수 경계도 다시 검사합니다. 바뀌지 않은 미분류 장비 때문에 전체 프리셋을 보류하지 않지만, 실제 변경 장비의 세트 소속이 불명확하면 추정하지 않습니다. 사용 탄약의 검증은 후속 조사 대상으로 유지합니다.

비공개 자동 정리는 큰 중복 API 응답 캐시와 완료 후 재생성할 수 있는 중간 파일을 제거하고, 최종 재계산·원본 무결성 검증이 끝난 가장 최근 날짜의 원본 DB만 남깁니다. 새 날짜가 미완료라면 가장 최근 미완료 날짜도 이어받기용으로 유지하며, 실행 잠금이 잡힌 자료는 지우지 않습니다. 오래된 미완료 날짜가 계속 쌓이지 않도록 정리합니다. 이름·식별자·직업·레벨·처리 우선순위 이력은 원본 응답을 포함하지 않는 압축 파일로 분리하여 30일 한도로 유지합니다. 정리는 수집 시작과 최종 재계산·공개 파일 준비 후 자동 실행됩니다. 이 규칙은 실제 수집기를 실행할 때 적용되며, 다른 PC의 예약이나 파일이 이 PC에 자동으로 이전된다는 뜻은 아닙니다. 홈페이지의 공개 순위·코디 보관은 기존 7일을 유지합니다.

## 22일 전체 재수집과 계산기 재구현 — 2026-10-23

다른 PC의 중단된 체크포인트를 이어받지 않고 22일 후보와 API 원본을 새로 수집합니다. 290~300레벨을 등재 대상으로 유지하고 후보 탐색에는 289레벨 경계를 포함합니다. 전일에 확인된 이름·식별자도 후보의 합집합으로 확인하며, 과거 전투력은 처리 순서에만 사용합니다. 실제 새 이름·월드 조합과 289→290 승급 후보는 과거 미처리 후보와 구별하여 우선 처리합니다.

비공개 `preset-api-v13`은 이 PC에 있는 계산 원본을 바탕으로 다시 구현했습니다. 이전 PC의 v12 비공개 소스를 확보했다고 간주하지 않습니다. 착용 전투력을 독립 계산하여 정수 단위로 일치한 경우에만 장비·하이퍼·어빌리티·유니온 조합을 비교합니다. 현재 번호의 프리셋 옵션과 실제 현재 옵션이 다르면 보류하고, 없는 대체 프리셋을 현재 값으로 채우지 않습니다. API가 제공하지 않는 사용 탄약은 계속 보류합니다.

장비 변경마다 추가 특수반지의 슬롯 개방과 액티브·패시브 중복 조건을 다시 검사합니다. 비활성 소울 잠재옵션을 제외하며 원본 응답은 수정하지 않습니다. 유니온 대원 효과는 [6월 18일 개편](https://maplestory.nexon.com/news/update/806)에 따라 배치와 무관한 반환값을 유지하고, API에 노출된 유니온 스탯 프리셋을 비교합니다. 무기 보정은 원본 구성요소의 정수 추가옵션 단계와 스타포스가 각각 확인되는 경우만 지원합니다. 제로의 별도 무기 규칙은 일반 무기 규칙으로 추정하지 않습니다.

럭키 무기가 유지돼도 다른 장비의 개수가 경계를 넘으면 적용 세트 개수가 추가로 달라집니다. 이전 API 세트 개수와 실제 기본 구성의 일치를 확인한 뒤 [럭키 아이템 적용 조건](https://maplestory.nexon.com/News/Update/483)을 반영합니다. 같은 날짜의 세트 정의가 이름만 같고 효과가 다르면 타 캐릭터의 정의를 대신 사용하지 않습니다. 확인하지 못한 장비·세트 변경은 보류합니다.

보유 안드로이드는 실제 착용 심장과의 호환 근거가 확인되는 조합만 사용합니다. 불명확한 조합은 실제 장비의 수학적 상한이 확인된 최대값을 넘지 못함을 증명할 수 있을 때만 생략하며, 상한 계산에 사용하는 가상의 활성 상태를 공개 조합으로 사용하지 않습니다. 공개값의 계산 범위는 `presets-and-owned-android`로 유지합니다.

전체 후보 조회 후 최종 세트 정의로 저장 원본을 네트워크 없이 다시 계산합니다. 재계산 전 결과를 별도 보존하고, 모든 원본의 해시가 재계산 전후 같음을 검사합니다. 이번 교체본에는 이전 v12 행을 이월하지 않으며, 검증 인원이 줄어도 새 규칙에서 보류된 값을 과거 수치로 복원하지 않습니다. 조회 완료·검증 통과·API 오류·검증 보류를 구분하여 공개하고, 전체 검사와 PR CI를 통과한 뒤 배포합니다.

수집·재확인·후보 탐색의 넥슨 API 호출 합계는 2,752,660회입니다. 22일 공개 순위와 코디 이력은 유지하며, 비공개 원본은 검증 완료한 최신 23일 하루치만 남기는 기존 자동 정리 정책을 적용합니다. 최근 후보 메타데이터 30일 보관과 공개 기록 7일 보관은 그대로 유지합니다.


## 2026-10-25 기록부터 사냥 세팅의 API 착용값 보존

모든 장비 프리셋이 사냥 세팅이라는 이유로 실제 API 착용 전투력까지 제외하던 경로를 수정했습니다. 사냥 장비 프리셋은 가정 계산 후보에서 계속 제외하며, 해당 날짜 API 착용값만 확인되면 그 값을 그대로 포함합니다. 계산하지 않은 프리셋 값과 조합은 null·0으로 남기고, 상세 화면에 API 값만 반영한 이유와 제외한 프리셋을 표시합니다. 부분 원본에 일부 사냥 장비가 확인된 경우에도 실제 API 값만 사용하며 전체 장비·프리셋을 확인했다고 표시하지 않습니다. 제논·데몬어벤져 제외와 날짜·신원·레벨·월드 검사는 유지합니다. 이전 날짜의 원본을 이 PC에 보유했다고 가정하거나 과거 공개 인원을 새 기준으로 다시 표시하지 않습니다.


2026-10-27 운영 확인: 26일 날짜의 전체 후보 217,386건을 시도하고 166,498명으로 공개 순위를 산정했습니다. 계산 보류·미처리는 0건이며 API 조회 실패 275건은 별도 표시합니다. 사냥 프리셋 제외가 실제 API 착용값까지 제외하지 않도록 PR43의 규칙을 수집기에 적용했습니다. 원본 전체 재계산·해시 보존, 49개 응답 직업 분류의 670개 원본 표본, TOP 3 8,349건, 사이트 테스트 81개를 확인했습니다. 기존 6개 날짜의 1,867개 참조 파일과 공개 앱 다운로드를 보존하며 공개 기록 7일·원본 최신 하루·후보 이력 30일 기준을 유지합니다.


## 공유 치장과 프리즘 표시 — 2026-10-30

비공개 코디 추출기는 공유 기본 슬롯을 활성화·성별·직업별 적용 부위로 선별하고 컬러링 프리즘의 실제 적용 플래그를 확인합니다. 공유 장비의 능력치 유효기간 종료만으로 영구 외형을 제거하지 않습니다. 코디 프리셋과 전투력 계산 프리셋은 계속 별개입니다.

코디 상세의 `outfit_source=world_shared`는 공유 기본 슬롯이 반영된 목록이고, `unverified`는 동일 기준일·이름·월드·이미지 해시를 재확인하지 못해 목록 표시를 보류한 기록입니다. 후자는 아이템을 빈 배열로 유지하며 기존 순위와 이미지를 바꾸지 않습니다. 원본 또는 날짜 고정 API로 동일 기록을 다시 확인한 경우에만 목록을 복원합니다. 최신 식별자의 현재 코디를 과거 기록에 복사하지 않습니다.


## 공유 치장 수정본 프로그램 재배포 — 2026-10-30

사용자의 후속 재배포 요청으로 PC 2.0.7·Android 1.0.8(versionCode 19)을 공개했습니다. 공유 기본 치장 선택·직업/성별 적용과 상세 표시 보완을 네이티브 배포본에 포함했습니다. 직전 절의 소스만 반영한 상태에서 실제 공개 설치 파일까지 갱신한 후속 작업입니다. 명예의전당 순위와 코디 기록은 이번 프로그램 배포에서 변경하지 않습니다. 검증 범위는 `docs/release-207-108-validation.md`를 확인하세요.


## 공개 식별자 보호 — 2026-10-31

[NEXON AI 에이전트 가이드](https://openapi.nexon.com/ko/guide/ai-agent/)를 검토하여 공개 순위·코디 자료에 API 원본 OCID를 내보내지 않도록 수정했습니다. 공개 형식의 `ocid` 필드는 호환성을 위해 유지하지만, 값은 `mt_` 접두사와 `SHA-256("mapletools-public-character-v1" + NUL + 원본 식별자)`로 생성한 공개 연결 키입니다. 이 값으로 NEXON API를 호출하면 안 됩니다. 비공개 수집기는 원본 API 식별자로 조회하고 공개 연결 키로 변환하여 순위·코디를 연결합니다. 같은 공개 키의 재변환은 멱등적입니다.

현재 제공하는 23~29일의 공개 순위·코디 기록 225,547개를 변환했습니다. 모든 행은 식별자를 제외한 필드가 변환 전과 같은지 비교했고 전투력·순위·수집 시각·이미지·프리셋 계산값을 변경하지 않았습니다. 전체 원본 재수집과 API 호출은 없었습니다. 모든 현행 공개 파일과 배포 ZIP·APK의 중첩 압축 항목을 검사하여 사용 중인 키 및 키 조각이 없음을 확인했습니다. 과거 Git 커밋은 이번 변경으로 삭제되지 않습니다.

신규 전체·증분·과거 기록·코디 게시 경로에서도 동일한 변환을 수행하며, 공개 자료 검증기는 원본 식별자가 순위에 들어가면 실패합니다. 비공개 게시 감사는 gzip-base64 자료와 ZIP·APK 내부까지 검사하고 실제 사용 키와 키 조각이 검출되면 게시를 중단합니다. 원본 증거 DB는 비공개 영역에 유지하며 식별자 변환으로 수정하지 않습니다.
