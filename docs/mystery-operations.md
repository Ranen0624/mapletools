# 전투력 명예의 전당 운영

## 사냥 프리셋 제외·월드리프 식별·원본 하루 보관 — 2026-10-23

사용자 요청에 따라 `preset-api-v14`부터 어비스 헌터 링·어비스 헌터스 링·정령의 펜던트·스페셜 정령의 펜던트가 있는 장비 프리셋을 최대값 비교에서 제외합니다. 모든 장비 프리셋이 이 조건에 해당하면 순위 대상에서 제외합니다. 사냥 프리셋 제외는 경험치 옵션으로 전투력 상한을 추정한 결과가 아니라 사용자가 정한 집계 기준입니다. 다른 경우 현재 착용 전투력의 독립 검산은 계속 정확히 일치해야 합니다. 현재 착용 프리셋 자체가 제외되면 남은 프리셋의 최대값이 API 착용 전투력보다 작을 수 있으므로, 제외한 프리셋과 집계 정책을 공개 자료·화면·개인 CSV에 명시합니다. 집계 정책이 다른 기록은 한 순위에 섞지 않습니다.

월드리프·개명으로 후보와 실제 응답의 이름·월드가 달라졌다는 이유만으로 보류하지 않습니다. [NEXON 공식 안내](https://openapi.nexon.com/ko/support/notice/2450396/)처럼 월드리프 시 식별자도 바뀔 수 있으므로, 요청한 날짜의 식별자와 `character/basic`의 실제 정보를 확인합니다. 같은 식별자의 중복 후보는 한 번만 등재하고, 같은 날짜 원본의 실제 신원이나 계산값이 충돌하면 보류합니다. 장비 세트 재구성은 API가 반환한 현재 세트 개수에 실제 변경 장비의 영향을 반영하며 럭키 무기의 개수 경계도 다시 검사합니다. 바뀌지 않은 미분류 장비 때문에 전체 프리셋을 보류하지 않지만, 실제 변경 장비의 세트 소속이 불명확하면 추정하지 않습니다. 사용 탄약의 검증은 후속 조사 대상으로 유지합니다.

비공개 자동 정리는 큰 중복 API 응답 캐시와 완료 후 재생성할 수 있는 중간 파일을 제거하고, 최종 재계산·원본 무결성 검증이 끝난 가장 최근 날짜의 원본 DB만 남깁니다. 새 날짜가 미완료라면 가장 최근 미완료 날짜도 이어받기용으로 유지하며, 실행 잠금이 잡힌 자료는 지우지 않습니다. 오래된 미완료 날짜가 계속 쌓이지 않도록 정리합니다. 이름·식별자·직업·레벨·처리 우선순위 이력은 원본 응답을 포함하지 않는 압축 파일로 분리하여 30일 한도로 유지합니다. 정리는 수집 시작과 최종 재계산·공개 파일 준비 후 자동 실행됩니다. 이 규칙은 실제 수집기를 실행할 때 적용되며, 다른 PC의 예약이나 파일이 이 PC에 자동으로 이전된다는 뜻은 아닙니다. 홈페이지의 공개 순위·코디 보관은 기존 7일을 유지합니다.

## 22일 전체 재수집과 계산기 재구현 — 2026-10-23

다른 PC의 중단된 체크포인트를 이어받지 않고 22일 후보와 API 원본을 새로 수집합니다. 290~300레벨을 등재 대상으로 유지하고 후보 탐색에는 289레벨 경계를 포함합니다. 전일에 확인된 이름·식별자도 후보의 합집합으로 확인하며, 과거 전투력은 처리 순서에만 사용합니다. 실제 새 이름·월드 조합과 289→290 승급 후보는 과거 미처리 후보와 구별하여 우선 처리합니다.

비공개 `preset-api-v13`은 이 PC에 있는 계산 원본을 바탕으로 다시 구현했습니다. 이전 PC의 v12 비공개 소스를 확보했다고 간주하지 않습니다. 착용 전투력을 독립 계산하여 정수 단위로 일치한 경우에만 장비·하이퍼·어빌리티·유니온 조합을 비교합니다. 현재 번호의 프리셋 옵션과 실제 현재 옵션이 다르면 보류하고, 없는 대체 프리셋을 현재 값으로 채우지 않습니다. API가 제공하지 않는 사용 탄약은 계속 보류합니다.

장비 변경마다 추가 특수반지의 슬롯 개방과 액티브·패시브 중복 조건을 다시 검사합니다. 비활성 소울 잠재옵션을 제외하며 원본 응답은 수정하지 않습니다. 유니온 대원 효과는 [6월 18일 개편](https://maplestory.nexon.com/news/update/806)에 따라 배치와 무관한 반환값을 유지하고, API에 노출된 유니온 스탯 프리셋을 비교합니다. 무기 보정은 원본 구성요소의 정수 추가옵션 단계와 스타포스가 각각 확인되는 경우만 지원합니다. 제로의 별도 무기 규칙은 일반 무기 규칙으로 추정하지 않습니다.

럭키 무기가 유지돼도 다른 장비의 개수가 경계를 넘으면 적용 세트 개수가 추가로 달라집니다. 이전 API 세트 개수와 실제 기본 구성의 일치를 확인한 뒤 [럭키 아이템 적용 조건](https://maplestory.nexon.com/News/Update/483)을 반영합니다. 같은 날짜의 세트 정의가 이름만 같고 효과가 다르면 타 캐릭터의 정의를 대신 사용하지 않습니다. 확인하지 못한 장비·세트 변경은 보류합니다.

보유 안드로이드는 실제 착용 심장과의 호환 근거가 확인되는 조합만 사용합니다. 불명확한 조합은 실제 장비의 수학적 상한이 확인된 최대값을 넘지 못함을 증명할 수 있을 때만 생략하며, 상한 계산에 사용하는 가상의 활성 상태를 공개 조합으로 사용하지 않습니다. 공개값의 계산 범위는 `presets-and-owned-android`로 유지합니다.

전체 후보 조회 후 최종 세트 정의로 저장 원본을 네트워크 없이 다시 계산합니다. 재계산 전 결과를 별도 보존하고, 모든 원본의 해시가 재계산 전후 같음을 검사합니다. 이번 교체본에는 이전 v12 행을 이월하지 않으며, 검증 인원이 줄어도 새 규칙에서 보류된 값을 과거 수치로 복원하지 않습니다. 조회 완료·검증 통과·API 오류·검증 보류를 구분하여 공개하고, 전체 검사와 PR CI를 통과한 뒤 배포합니다.

데스티니 전용 ‘초월 : 결전의 의지’는 [공식 착용 조건](https://maplestory.nexon.com/news/update/767)에 따라 데스티니 무기를 벗은 조합에 이월하지 않습니다. 다른 무기에서 제네시스·데스티니로 바꾸는 경우에도 필요한 해방·초월 스킬의 실제 근거가 없으면 효과를 임의로 채우지 않고 보류합니다.

일일 수집기는 완료한 캐릭터의 압축 원본 DB를 체크포인트로 사용하므로, 큰 API 응답을 별도 디스크 캐시에 중복 저장하지 않습니다. 이름·식별자 캐시, 실행 중 메모리 캐시와 동일 요청 병합은 유지합니다. 중단 시 아직 원본 저장이 끝나지 않은 캐릭터는 재조회할 수 있으나 완료한 원본은 다시 내려받지 않습니다. 공개 순위·코디의 7일 보관은 전체 API 원본·응답 캐시의 7일 보관을 뜻하지 않습니다.

## 캐시 효과·남은 보류 재검증 — 2026-10-24

`preset-api-v15`는 22일의 기존 원본으로 다시 검산합니다. 사용탄약은 계속 보류합니다. 캐시 개별 능력치는 실제 능력치 적용 슬롯에서 한 번만 계산하고, 코디 프리셋의 아이템 옵션을 추가 합산하지 않습니다. 엔젤릭버스터의 캐시 세트 효과는 공식 세트 아이템 가이드에 따라 일반·드레스업 두 모드에서 파츠 수가 가장 많은 세트 하나를 적용합니다. 같은 개수에서 효과가 다르면 드레스업 파츠 수를 확인하며, 이를 확정할 수 없으면 보류합니다. 개별 옵션의 드레스업 슬롯 규칙을 세트 선택 규칙과 혼동하지 않습니다. 월드 공유의 성별에 따른 개별 옵션 제외와 API의 세트 효과는 같은 규칙으로 단정하지 않습니다. 원본 착용 전투력과 일치하지 않으면 계속 보류합니다.

[마스터라벨 공식 가이드](https://maplestory.nexon.com/Guide/N23GameInformation/Articles/428)에 따라 캐시 기본 슬롯 또는 코디 프리셋의 마스터라벨을 같은 부위당 한 번만 셉니다. 능력치 유효기간과 성별을 확인하며, 날짜 지정 `character/other-stat`에 활성화된 전투 플러스가 실제 반환된 경우에만 공식 단계별 효과를 비교합니다. 구독을 구매했다고 추정하거나 다른 캐릭터의 효과를 새로 더하지 않습니다. API에 이미 반환된 효과를 중복 합산하지 않고, 원본에 보이는 본인의 기본 슬롯·코디 프리셋으로 확인 가능한 조합만 비교합니다. 이 범위는 `configuration_scope=presets-owned-android-cash-plus`, `cash_effect_policy=cash-base-and-confirmed-plus-v1`로 구분하며 이전 계산 범위와 한 수집본에 섞지 않습니다. 선택이 필요한 코디 프리셋은 상세와 CSV에 남깁니다.

조회 오류 5,729명 전원에 대해 날짜 지정 기본 정보와 유니온 챔피언을 재확인했습니다. 4,645명은 기본 정보가 있으나 유니온 챔피언 조회가 `OPENAPI00004`로 거부됐고, 1,084명은 기본 정보 자체가 `OPENAPI00003` 또는 `OPENAPI00004`로 거부됐습니다. 이는 해당 API가 응답한 실패 지점이며 캐릭터 삭제나 미등록을 확정한 뜻이 아닙니다. 날짜를 뺀 최신 응답은 비교 진단에만 사용하며 22일 계산 원본에 합치지 않습니다. 실패한 요청과 이미 성공한 같은 날짜 응답은 압축 체크포인트로 저장하여 다음 재시도 때 실패 지점부터 확인합니다. 불완전한 체크포인트는 계산 입력이 될 수 없습니다. 따로 확인한 API 착용 전투력은 다음 수집의 우선순위 힌트로만 남기며, 후보 메타데이터의 `confirmed=false`를 유지합니다. 이 힌트는 검증된 프리셋 전투력이나 공개 순위로 승격하지 않습니다.

## 22일 보류 원인별 재검증 — 2026-10-23

20일·19일 재수집은 보류하고 22일 계산 검증을 먼저 진행합니다. 현재 착용 API 전투력과 정확히 일치해야 한다는 조건은 그대로 유지합니다. 수정 전 결과와 실제 원본 해시를 보존한 뒤 네트워크 없이 전체 저장 원본을 다시 계산합니다. 기존 공개 기록도 같은 규칙으로 재검증하며, 새 규칙에서 최대 조합을 확정할 수 없으면 보류로 돌립니다.

엔젤릭버스터의 일반·드레스업 캐시 세트는 [공식 가이드](https://maplestory.nexon.com/Guide/N23GameInformation/Articles/415)에 따라 중복 합산하지 않습니다. 동일 개수의 세트가 서로 다른 전투 옵션을 가져 적용 대상을 확정할 수 없으면 계속 보류합니다. 제로의 월드 공유 치장은 [공식 업데이트](https://maplestory.nexon.com/news/update/815)의 알파·베타 동시 적용 기준을 사용하며, 다른 직업의 성별을 추정하지 않습니다. 프리셋 변경 시 럭키 장비의 적용 조건도 다시 확인합니다. 알려지지 않은 세트나 조건부 장비의 효과를 추측하지 않습니다.

아티팩트는 [공식 API 정의](https://openapi.nexon.com/ko/game/maplestory/?id=15)의 능력치 유효 여부(`0`: 유효, `1`: 유효하지 않음)를 확인합니다. 날짜만 보고 만료로 보류했던 원본은 일일 기준일·모든 크리스탈의 상태·유효 크리스탈의 옵션별 레벨 합계와 실제 반환 효과가 모두 일치할 때만 해당 경고를 해제합니다. 반환된 효과 수치를 바꾸거나 만료 효과를 복원하지 않으며 다른 시점 충돌 경고는 유지합니다.

추가 특수 반지 슬롯은 [공식 적용 조건](https://maplestory.nexon.com/News/Update/799)에 따라 일반 반지 슬롯의 4레벨 이상 리스트레인트 링·컨티뉴어스 링과 액티브·패시브 각각 1종 조건을 확인합니다. 프리셋을 바꿀 때마다 활성 여부를 다시 판단하고, 슬롯이 열리지 않았으면 저장된 예비 반지의 능력치를 합산하지 않습니다. 반지 종류·레벨·시점을 확인할 수 없으면 보류합니다.

무기 보정은 장비 레벨·실제 추가옵션 단계·주문서·스타포스 구성요소를 확인한 강화 조합만 지원합니다. 제네시스 시즈건 등 기존에 빠졌던 조합의 지원을 넓혔으며, 반올림 비율이나 캐릭터 전투력에 맞춰 추가옵션 단계를 고르지 않습니다. 제로의 별도 추가옵션 규칙과 확인할 수 없는 강화 상태는 이 일반 무기 규칙에 넣지 않습니다.

화살·표창·불릿의 공격력은 [공식 업데이트](https://maplestory.nexon.com/News/Update/741)에 따라 전투력에 반영됩니다. 현재 공식 캐릭터 API에는 사용 중인 탄약을 확인할 항목이 없습니다. `preset-api-v11`부터 최고급 탄약이나 미장착을 임의로 가정한 계산은 공개 검증 통과로 취급하지 않습니다. 해당 원본은 직업 제외가 아닌 `ammunition_source_unavailable` 사유의 검증 보류로 남기고, 선택한 직업의 화면에 이유를 표시합니다. ## 날짜별 저장 구조

mystery-config.json의 staticCatalog가 data/mystery-dates.json을 가리킵니다. catalog.latest가 최신일이고 dates[].index가 해당 날짜의 변경 불가한 목록을 가리킵니다. 선택한 날짜가 없으면 미수집으로 표시하며 다른 날짜로 대체하지 않습니다. 공유 링크는 date=YYYY-MM-DD를 지원합니다.

schema_version=2 목록은 query별 레벨 인원수와 상위 10명 참조를 저장합니다. 캐릭터는 날짜별 공유 풀에 한 번만 저장하고 gzip/base64 JSON으로 압축합니다. 브라우저는 선택 부문에 필요한 풀만 읽고 검증합니다. 레벨별 TOP 10의 합집합은 임의의 레벨 구간 TOP 10을 정확히 보존합니다. 표시 인원은 전체 API 검증 수이며 저장된 상위 행 개수와 구분합니다. JSON/CSV 다운로드는 선택한 검증 기록으로 기기에서 생성합니다.

새 파일을 모두 기록한 뒤 catalog를 원자적으로 교체합니다. 사용자가 최근 7일 보관을 명시적으로 요청했으므로 mystery-config.json의 historyRetentionDays 기본값은 7입니다. 최신 공개일을 포함한 최근 7개 달력 날짜를 유지하며 새 공개 시 scripts/mystery-retention.mjs가 기간이 지난 순위 풀·수정 전 파일·코디 상세·이전 방식의 조회 JSON/CSV를 정리합니다. 다른 파일과 PC·Android 배포물은 정리 대상에 포함하지 않습니다. 공개 기간 밖 과거 날짜의 재등록은 거절하며 최신일을 뒤로 돌리지 않습니다. 날짜별로 사용자가 내려받은 CSV는 계속 개인 기록으로 분석할 수 있습니다. Git 이력의 기존 커밋을 강제 재작성하지 않습니다.

용량 보호는 데이터 외 배포물·정적 자산까지 포함한 현재 공개 작업 폴더를 계산하며, 기간이 지난 파일을 제외해도 900MiB를 넘으면 공개 준비를 중단합니다. 이 검사는 1GB Pages 한도에 여유를 두기 위한 것이며 전송량 한도를 보장하지 않습니다. 보관 기간 확대 시 historyRetentionDays와 예상 사이트 용량을 함께 확인하세요. Worker/D1은 아직 연결하지 않았고 현재는 GitHub Pages만 사용합니다. 추후 키는 Worker secrets에만 둡니다.

## 캐릭터 상세와 개인 CSV 분석

1~10위의 이름 또는 시상대 이미지를 누르면 같은 기준일의 캐릭터 정보를 엽니다. 큰 공식 이미지·월드·직업·레벨·기준일·전투력·계산 프리셋을 즉시 표시합니다. 추가 코디 정보는 실제 저장된 character/basic 및 character/cashitem-equipment의 동일 캐릭터 자료에서 비공개 export_character_details.py로 추출하고 scripts/publish-mystery-details.mjs로 공개합니다. 실제 착용 코디 프리셋과 전투력 계산 조합을 구분합니다. 코디 아이템명·부위·라벨·컬러링 프리즘 및 길드·성별만 허용하며 미수집 헤어·성형을 추정하지 않습니다. 이름·월드·기준일·이미지 주소 해시를 대조하고, 자료가 없거나 일치하지 않으면 표시를 보류합니다. 캐릭터 상세 풀도 압축하며 클릭했을 때만 읽습니다. daily 수집 후 순위와 상세 정보를 함께 생성·검증하세요.

개인 CSV/JSON은 브라우저 메모리에서만 분석합니다. 파일의 실제 기준일을 사용하며 여러 날짜가 있으면 날짜별로 분리합니다. 날짜 열이 없을 때만 사용자가 입력한 기준일을 적용합니다. 공개 7일 보관 규칙은 개인 파일에 적용하지 않습니다. 선택한 날짜·직업·월드·레벨에 맞는 파일 내 순위와 최고·평균·중앙값을 표시하며, 홈페이지 공개 순위와 섞지 않습니다. API 재계산이나 미수집 코디를 만들어 내지 않습니다. 파일은 서버로 보내거나 저장하지 않고 새로고침하면 사라집니다. 5MiB/50,000행 이내, 290~300레벨의 유효한 정수 전투력 기록을 지원합니다.
