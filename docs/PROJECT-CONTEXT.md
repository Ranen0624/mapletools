이 정책은 이전의 ‘불완전 체크포인트는 공개 순위로 승격하지 않음’ 중 API 착용값 사용 제한만 대체합니다. 부분 체크포인트는 여전히 부분 자료이며 완전한 프리셋 원본으로 표시하거나 변환하지 않습니다. 원본 해시와 기존 공개 행을 보존하고 API-only 자료의 포함 수·실패 지점을 공개합니다. 기본정보나 전투력 자체가 없으면 포함하지 않습니다.
