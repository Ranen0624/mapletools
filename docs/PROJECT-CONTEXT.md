## 유지할 서비스 기준

2026-10-22부터 순위 기본값은 전일 날짜를 지정한 NEXON API 일일 기록입니다. API는 해당 날짜 00시~다음 날 00시 사이의 일일 자료를 다음 날 오전 2시부터 제공하며, 분 단위 23:59 시점을 지정하지 않습니다. 홈페이지에는 ‘API 일일 기록’으로 표시하고 정확한 분 단위 스냅샷이라고 설명하지 않습니다. 기존 일중 실시간 수집본은 ‘이전 수집본’으로 구분해 보관하며 새 일일 기록과 합치거나 날짜만 바꾸지 않습니다. 매일 오전 6시 예약은 전일 자료를 대상으로 유지합니다.

전투력 순위는 실제 API에서 확인한 290~300레벨만 대상으로 합니다. 일반 월드와 에오스·핼리오스를 분리합니다. 후보 이름 탐색에만 랭킹 API를 사용하며, 경험치 순위로 전투력 순위를 결정하지 않습니다. 오늘의 실제 장비·하이퍼·어빌리티·유니온 프리셋을 계산하고 착용 전투력과 검산이 일치한 기록만 공개합니다. 검증하지 못한 기록은 보류하고 가상 값이나 과거 최고값으로 채우지 않습니다. 제논·데몬어벤져는 프리셋 계산의 정확도가 확보되지 않아 제외하며 이유를 홈페이지에 안내합니다.

TOP 10 이름을 누르면 같은 수집본의 코디·기본 정보·전투력·계산 프리셋을 표시합니다. 공식 넥슨 이미지만 재사용합니다. 코디 상세는 실제 저장 자료와 이름·월드·기준일·이미지 해시가 일치할 때만 표시하며 미수집 항목을 추정하지 않습니다.

신규 날짜 고정 원본은 비공개 `<date>-daily-presets`에 저장하며 예전 `<date>-presets` 실시간 원본을 덮어쓰지 않습니다. 월드 이동 후 식별자가 바뀌면 새 식별자로 이동 전 날짜를 조회할 수 없는 경우가 있으므로 해당 날짜에 유효한 식별자로 확인합니다. 마스터라벨 월드 공유 옵션은 실제 활성화 상태·성별·유효기간을 확인해 공통 계산기에 한 번만 반영합니다.

공개 기록은 `mystery-config.json`의 `historyRetentionDays`에 따라 최근 7일만 유지합니다. 기간이 지난 순위·코디 파일만 정리합니다. 개인 CSV는 더 오래된 날짜도 파일의 기준일별로 분리하여 기기 안에서 분석하며, 공개 순위와 합치거나 서버로 전송하지 않습니다.

## 현재 컴퓨터에 있어야 하는 비공개 자료

운영용 작업 관리창과 API 수집·계산 소스는 별도 비공개 `private-collection/`에 있습니다. 필요한 이름은 `workbench.py`, `OPERATOR-NOTES.md`, `run_daily.py`, `collect_preset_sources.py`, `preset_combat.py`, `preset_batch.py`, `export_mystery_verified.py`, `export_character_details.py`, `audit_public.py`입니다. 이 파일들과 개발용 PC 프로그램 원본, 키·설정·서명 자료·수집 DB·로그는 공개 GitHub에 올리지 않습니다.

비공개 도구가 연결돼 있다면 먼저 `workbench.py doctor`, `workbench.py status`로 실제 경로와 실행 중인 수집을 확인합니다. `machine_paths.py`는 현재 PC의 경로를 찾고 `MAPLETOOLS_WEBSITE`, `MAPLETOOLS_PROGRAM`, `MAPLETOOLS_NODE` 또는 비공개 `workbench-config.json`으로 지정할 수 있습니다. 이전 PC의 절대 경로는 가져오지 않습니다. 없는 자료는 없다고 보고하고, 가능한 홈페이지 작업은 현재 저장소에서 이어갑니다.

수집 원본 DB를 옮겨 이어받으려면 이전 수집기의 정상 체크포인트와 SQLite 백업 절차가 필요합니다. 실행 중인 DB 파일 하나를 임의로 복사하거나 이전 PC의 프로세스 번호를 새 PC에서 사용하지 않습니다. API 키는 새 PC의 안전한 로컬 설정으로 별도 연결합니다.

## 검증과 공개

수집 → 저장 원본을 재사용한 병렬 계산 → 허용 필드만 공개 파일 생성 → 전체 검사 → 개발 브랜치/PR → CI 통과 → 정확한 head로 병합 → Pages 성공 및 실제 페이지 확인 순서입니다. 사용자는 매일 검증 후 자동 공개와 명확한 일부 수집 표시를 허용했습니다. 실제 예약이 어느 PC에 연결됐는지는 현재 앱에서 별도 확인합니다. 이 문서가 있다고 예약이나 키가 새 PC에 자동 등록된 것은 아닙니다. 서로 다른 PC에서 같은 날짜를 중복 수집하지 않도록 확인합니다.

홈페이지는 GitHub Pages와 정적 압축 JSON을 사용합니다. D1/Workers는 향후 확장용이며 연결 여부를 실제 설정으로 확인합니다. PC 2.0.4·Android 1.0.5 공개 파일과 `releases.json`, CNAME을 보존합니다. 일반 기능 수정으로 새 PC/APK 공개판을 자동 생성하지 않습니다.
