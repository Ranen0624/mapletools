    시작 전에 궁금한 것들

    여기서 실제 캐릭터를 검색하나요?

    웹 체험판은 브라우저 안의 가상 데이터로 동작을 설명합니다. 명예의 전당은 사전 수집한 실제 검색 결과만 비교하며 미수집 부문을 안내합니다. 실제 캐릭터 조회는 프로그램에서 실행하고, 홈페이지에서는 API 키를 입력받지 않습니다.

    전투력 계산은 모든 직업에서 정확한가요?

    기본 검색은 API에 공개된 전투력을 사용합니다. 직접 계산과 프리셋 예상값은 별도 기능이며, 제논·데몬어벤져와 일부 자료 시점 차이에 따른 오차가 남아 있습니다. 프리셋 유추는 기본 해제이고, 현재 계산이 정확히 일치하는 등 검증 조건을 만족한 경우에만 사용합니다.

    조회한 결과가 전체 캐릭터를 뜻하나요?

    아닙니다. 선택한 랭킹 범위와 공개 API의 제공 범위 안에서 찾은 결과입니다. 미등록 유니온 챔피언, 누락된 응답, 수집 페이지 한도에 따라 일부 대상은 확인되지 않을 수 있습니다.

    기존 앱은 어떻게 업데이트하나요?

    아래에서 PC 2.0.4 공개 ZIP과 Android 1.0.5 공개 APK를 받을 수 있습니다. Android는 기존 앱을 삭제하지 않고 새 APK를 설치하면 설정을 유지하며 업데이트할 수 있어요. 두 공개판 모두 본인의 NEXON Open API 키를 사용합니다.

    ABOUT MAPLETOOLS

    메이플툴즈는 어떤 도구인가요?

    메이플스토리 캐릭터의 장비·유니온·코디부터 전투력·HEXA까지.
    궁금한 정보를 찾고 비교하는 비공식 검색 도구입니다.

    장비 검색·추적

    스타포스·잠재능력·에디셔널·추가옵션으로 장비를 찾고, 검색 결과를 저장·비교해 보세요.

    장비 변경을 실시간으로 감시하는 기능은 제공하지 않습니다.

    유니온 캐릭터 검색

    직업과 레벨을 골라, 공개된 유니온 챔피언 등록 캐릭터를 살펴보세요.

    계정의 모든 부캐릭터를 자동으로 찾는 기능은 제공하지 않습니다.

    캐릭터 변화 이력

    공개 기록을 바탕으로 닉네임·길드·월드·코디 변화와 레벨 달성 기록을 확인하세요.

    기록 범위와 확인 시점에 따라 일부 이력이 없을 수 있습니다.

    장비·유니온·코디 검색은 PC · Android 프로그램에서.
    웹 체험판에서는 가상 데이터로 검색 흐름을 미리 확인할 수 있어요.
